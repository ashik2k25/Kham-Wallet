# খাম ওয়ালেট (Kham Wallet - Customizable bKash Envelope Manager)

সম্পূর্ণ কাস্টমাইজযোগ্য এনভেলপ মানি ম্যানেজার ও বিকাশ লাইভ-সিঙ্ক অ্যান্ড্রয়েড অ্যাপ।

## বৈশিষ্ট্যসমূহ:
- **৬টি কাস্টমাইজযোগ্য খাম (খাম ১ – খাম ৬):** যেকোনো ব্যবহারকারী প্রতিটি খামের নাম (Rename), বিবরণ, নির্ধারিত বাজেট এবং লক/আনলক স্ট্যাটাস নিজের মতো করে পরিবর্তন করতে পারবেন।
- **বাজেট অনুযায়ী অটো-ভাগ:** প্রতিটি খামে সেট করা বাজেট অনুপাতে প্রাপ্ত টাকা স্বয়ংক্রিয়ভাবে সব খামে ভাগ হয়ে যাবে।
- **বিকাশ লাইভ সিঙ্ক:** বিকাশ SMS ও নোটিফিকেশন থেকে স্বয়ংক্রিয়ভাবে লেনদেন শনাক্ত করে সচল খামের হিসাব আপডেট করে।

## GitHub Actions দিয়ে APK বিল্ড করার নিয়ম:
1. এই ফোল্ডারের সব ফাইল (`.github/workflows/build.yml` সহ) GitHub রিপোজিটরিতে আপলোড করুন।
2. **Actions** ট্যাব থেকে **Build Kham Wallet APK** ওয়ার্কফ্লো রান করুন।
3. বিল্ড শেষ হলে **Artifacts** থেকে `KhamWallet-bKashSync-APK` ডাউনলোড করে ইনস্টল করুন।
